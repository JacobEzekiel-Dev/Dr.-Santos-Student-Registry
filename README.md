How it works


You run the program and see a list of options (a menu).
You type a number to pick what you want to do.
It does that thing, then shows you the menu again.
Type 0 when you're done.  

How it remembers students

Think of 5 lists sitting side by side, like columns in a spreadsheet:
one column for IDs, one for names, one for majors, one for GPAs, one for
credits. Student 1's stuff is always in row 1 across all 5 columns.
Student 2's stuff is in row 2. And so on. 

small problem I ran into

Typing a name like "Alice Johnson" was getting cut down to just
